# Product Management Application

A modern React + Vite application that integrates REST APIs to provide user authentication, product browsing, search, filtering, sorting, pagination, and detailed product views. Built with reusable components and a responsive UI.

## Features

- User Login & Authentication
- Protected Routes
- Product Listing
- Product Search
- Category Filtering
- Product Sorting
- Pagination (Limit & Skip)
- Single Product Details
- Responsive Design
- Reusable Components
- Generic API Methods

## Tech Stack

- React
- Vite
- JavaScript (ES6+)
- React Router
- Axios / Fetch API
- Tailwind CSS
- DummyJSON REST API

## Installation

```bash
git clone <repository-url>
cd <project-folder>
npm install
npm run dev
```
